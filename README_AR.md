# مصروفي PWA — تطبيق ويب يعمل دون إنترنت

هذه نسخة تجريبية من تطبيق مصروفي تعمل كـ PWA بعد نشرها على استضافة HTTPS وفتحها مرة واحدة على كل جهاز.

## المميزات
- الراتب بالدولار والمصروفات بالشيكل.
- سعر صرف يدوي لكل دورة راتب.
- بدء دورة الراتب في اليوم الذي تستلمين فيه الراتب، مهما اختلف الموعد شهريًا.
- تصنيفات للمصروفات.
- ميزانيات حسب التصنيف وتنبيه عند بلوغ 80% من الحد أو تجاوزه.
- حفظ محلي منفصل على كل جهاز.
- تصدير واستيراد نسخة احتياطية JSON يدويًا.
- Service Worker للتشغيل دون إنترنت بعد أول زيارة ناجحة.

## الملفات
- `index.html`: التطبيق كاملًا.
- `manifest.json`: إعدادات التثبيت على الشاشة الرئيسية.
- `sw.js`: التخزين المؤقت والعمل دون إنترنت.
- `icon.svg`: أيقونة.

## تشغيله على iPhone وSamsung
يجب أولًا رفع هذه الملفات إلى استضافة تدعم HTTPS. يمكن استخدام GitHub Pages أو استضافة ثابتة مشابهة. لا يكفي فتح `index.html` كملف محلي لتفعيل التثبيت والعمل دون إنترنت.

### iPhone
1. افتحي رابط HTTPS في Safari.
2. افتحي قائمة المشاركة.
3. اختاري Add to Home Screen / إضافة إلى الشاشة الرئيسية.
4. افتحي مصروفي من الأيقونة واتركيه يحمل الملفات أول مرة، ثم جرّبي وضع الطيران.

### Samsung / Android
1. افتحي رابط HTTPS في Chrome.
2. من القائمة اختاري Install app أو Add to Home screen.
3. افتحي التطبيق مرة مع الإنترنت، ثم جرّبي وضع الطيران.

## ملاحظات مهمة
- البيانات محفوظة محليًا وبشكل منفصل على كل جهاز، تماشيًا مع خيار A. لن تظهر مصروفات الآيفون على تابلت سامسونج تلقائيًا.
- استخدمي «تصدير نسخة احتياطية» بانتظام. يمكن نقل ملف النسخة يدويًا ثم استيراده على الجهاز الآخر، لكن الاستيراد يستبدل بيانات الجهاز المستقبِل.
- سعر الصرف لا يتحدث تلقائيًا.
- هذه نسخة أولية وليست منشورة على متجر التطبيقات.
- للتوزيع العام، يفضّل إضافة أيقونات PNG بأحجام متعددة وفحص التوافق على الأجهزة المستهدفة.
